    الكود والإعدادات تذهب مباشرة من متصفحك إلى مستودعك؛ لا خادم وسيط.

    الربط بحساب GitHub

    1. افتح إنشاء رمز وصول دقيق (Fine-grained token).
    2. في Repository access اختر Only select repositories ثم مستودع H2APK وحده.
    3. في Permissions اجعل Contents: Read and write، وActions: Read-only.
    4. اضغط Generate token وانسخ الرمز والصقه هنا.

    تذكّر الرمز على هذا الجهاز
    وإلا يُنسى عند إغلاق المتصفح
    الرمز يبقى في متصفحك فقط ويُرسل إلى GitHub وحده. لا تستعمل التذكّر على جهاز مشترك، واحصر الرمز في مستودع H2APK كما في الخطوات.
